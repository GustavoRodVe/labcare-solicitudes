# Registro de uso de inteligencia artificial

Durante el examen usé Claude Code (modelo Claude Opus 5.5) como asistente dentro del editor, tal como permite la sección 10 del enunciado. Le pedí ayuda para leer el caso, proponer la estructura, escribir el código y la documentación, y automatizar las pruebas. Cada sugerencia la revisé, la ejecuté y la comprobé con pruebas antes de dejarla en el proyecto. No compartí credenciales: la contraseña de MySQL se generó y se guardó en el archivo `.env` sin mostrarse en la conversación.

## Cómo verifiqué las sugerencias

No di por bueno ningún fragmento solo porque se veía correcto. Lo que hice fue ejecutar las pruebas automatizadas después de cada cambio, revisar en MySQL que los datos realmente se guardaran o se rechazaran, y probar a mano las transiciones no permitidas desde la interfaz. También leí cada archivo para poder explicar qué hace, en especial el servicio de solicitudes, donde están las reglas de negocio.
